## Learner Journey

The learner journey has been refined around the agreed AI learning videos and quizzes scope:

1. Learner lands on the Stanbic IBTC STEM Series welcome/login page.
2. After login, the learner is routed to `/lms/programs`.
3. The learner chooses a learning level: Primary, JSS, or Senior Secondary.
4. The selected level opens the mapped courses for that program only.
5. Learners watch the AI learning videos and complete the quizzes for the selected course.

The mixed course/category listing is no longer presented as the main learner journey. Direct course-management views remain available for authorized admin and instructor users where needed.

## Quiz Scoring And Completion Experience

Quizzes now use a default pass mark of 60 percent.

Objective quiz submissions show different completion states based on score:

- Below 60 percent: learner sees a "Keep going" state, the score, the required pass mark, and a prompt to review and try again.
- 60 to 89 percent: learner sees a passed state with a trophy-style result visual.
- 90 percent and above: learner sees an excellent-result state with a stronger celebration visual.

Confetti is only shown for successful objective quiz submissions. Open-ended quiz submissions keep the existing instructor-review message.

Learners can see their previous quiz attempts, with the latest attempt shown first. Teachers and administrators can review grouped learner submissions, with the latest score surfaced while previous attempts remain available.

## Administrator And Teacher Role

Administrator and teacher capabilities include:

- Managing programs, courses, lessons, and quizzes.
- Setting quiz pass percentage, maximum attempts, duration, and submission-history visibility.
- Reviewing learner quiz submissions.
- Seeing grouped submissions by learner, including latest attempt and previous attempts.
- Tracking learner participation and course progress where the LMS provides the underlying data.

Admin and instructor views intentionally retain management functions that are hidden or de-emphasized in the learner journey.
