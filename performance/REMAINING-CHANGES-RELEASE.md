# Performance remaining-change release

This release brings the locally retained appraisal lifecycle work and the still-applicable fixes from PR #70 onto current `main`. PR #39 was merged separately with an identical application tree: its LMS authentication layout changes were already delivered.

## Included behavior

- Authorized reviewers can cancel an active appraisal, move it to Removed appraisals, and restore its retained history. Employees cannot perform these management actions. Completed outcomes require HR/admin removal and restoration and cannot be cancelled. A reason is optional; confirmation is required. No permanent deletion is introduced.
- Cancellation preserves evidence and audit history, stops reminders and local call access, and prevents resumed assessment writes. Active native participants block cancellation. Concurrent joins and late calendar scheduling are fenced; failed remote cancellation stays visible and retryable. Closed linked competency assessments retain authorized historical reports and privacy/retention controls.
- Goal check-ins can be appended without supplying an optional retry key. Populated keys remain unique per tenant and goal, and check-in sequence uniqueness remains. The deployment runs a build-and-verify-first index migration before retiring only the recognized legacy index; evidence records and unrelated indexes are retained. The CLI defaults to a read-only preview.
- Explicit organization-wide goal-decision grants now work on both approval endpoints while self-approval, tenant, relationship, deny and pending-state checks remain enforced.
- Analytics requires the relevant signed action and resource scope. Team membership or a review-only grant does not imply analytics access. Retired signed policy versions and failed required claims refresh require a fresh sign-in rather than authorizing stale privileges.
- HR selection uses the current scoped Identity directory. Collaboration pickers use a separate minimal Identity lookup for active app-assigned colleagues, authorized by existing feedback/recognition actions; this exposes no teams, roles, reviewers or appraisal data. Newly joined members and valid empty results are supported. Authentication/access/outage errors retain their status. A teamless member cannot inherit another organization's cached team or department.
- Final review shows the calculated evidence rating and explains the existing override justification rule. Discussion permissions and local-time inputs are corrected; mobile cycle editing, recognition tabs and one-on-one compose entry are improved. Removal/restoration and closed assessment screens explain their state and recovery path.

## PR #70 conflict resolution

The original PR predates the current architecture. Integration retains its useful fixes while preserving current schema5 identity permissions, the scoped Performance directory, selected-reviewer contracts, quarterly cycles, immutable competency reports, and corrected question labels. The earlier alternative schema4 migration, broad roster service, duplicate acceptance workflow and already-fixed OKR assignment index are superseded. The existing comprehensive CI and Core deployment workflows carry the new regressions instead.
