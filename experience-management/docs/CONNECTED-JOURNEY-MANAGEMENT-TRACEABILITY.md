**Overall state:** In progress — tested foundations span Phases 1–5, but no programme outcome is complete

This ledger is the completion authority for the programme. A plan paragraph,
type declaration, route name, screenshot, or passing narrow test is not proof
that a capability is delivered. A requirement moves to **Verified** only when
the implementation, negative controls, migrations where applicable, and the
named acceptance evidence all exist and pass against the current worktree.

## Status and evidence rules

| State | Meaning |
| --- | --- |
| Not started | No implementation evidence exists beyond the programme plan. |
| Foundation | Types, vocabulary, or an isolated primitive exists, but the user outcome and acceptance scenarios do not. |
| In progress | A usable slice exists, but at least one specified behaviour, control, migration, or verification gate is missing. |
| Implemented | The expected implementation exists, but required release evidence is incomplete or failing. |
| Verified | Positive and negative behaviour, migration/upgrade where relevant, security and entitlement enforcement, accessibility, and required runtime tests all pass. |
| Blocked | A recorded decision or external dependency prevents safe completion. This state never means “out of scope”. |

Required evidence classes:

1. **Code:** durable backend and frontend behaviour, not placeholder copy or a
   reserved enum.
2. **Data:** additive PostgreSQL migration, SQLite parity, reconciliation, and
   rollback/compatibility proof whenever state is introduced or changed.
3. **Controls:** tenant isolation, permission, entitlement, quota, retention,
   consent, and kill-switch behaviour appropriate to the capability.
4. **Tests:** unit/contract/integration/E2E plus negative and failure-injection
   cases matching the stated acceptance scenario.
5. **Runtime:** production-shaped PostgreSQL and browser/runtime evidence, not
   only source-text assertions.
6. **Operations:** telemetry, audit, alerts/runbooks, and a staged rollout gate
   for externally exposed or consequential behaviour.
